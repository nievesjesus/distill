## distill 0.9.0

### Audio and video
distill now transcribes recordings on your machine. Nothing is uploaded and no cloud speech service is involved.

```bash
distill-llm asr install                 # one time: about 35 MB runtime + 670 MB Parakeet model
distill-llm convert --stdout meeting.mp4
```

- **Formats:**
  - Audio: MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, AIFF.
  - Video: MP4, MOV, MKV, WEBM, AVI, M4V.
  - Files up to 2 GB in the CLI, the hook and the MCP server.
  - [ffmpeg](https://ffmpeg.org/) is required for everything except WAV.
- **On demand:** the npm package doesn't grow. `distill-llm asr install` downloads the speech runtime and one model into the cache folder. Each download is pinned by size and sha256 and can resume.
- **Models:** each user downloads only the one they choose:

  | Model | Languages | Download |
  | --- | --- | --- |
  | `parakeet` (default) | 25 European | ~670 MB |
  | `whisper-turbo` | ~99 | ~1,040 MB |
  | `whisper-small` | ~99 | ~375 MB |

  Install another with `asr install --model whisper-turbo`. Pick one per run with `--asr-model` or `DISTILL_ASR_MODEL`. Whisper detects the language; force it with `--language`.
- **Tokens:** transcripts are compact paragraphs with a timestamp about once a minute, and filler words are removed conservatively in English and Spanish. On two 28-minute recordings, the transcript is 54–67% smaller than the same speech as SRT.
- **Video:**
  - Key frames are OCR'd, and new on-screen text is added as `> [slide mm:ss]` blocks.
  - A video with no speech still gets its slides.
- **Agents:** `distill_file` accepts audio and video, and `distill_capabilities` reports which models are installed. In Claude Code, the plugin's skill handles these files: Claude's Read refuses binary files before hooks run.
- Transcripts are cached by file, model and language, so asking again is instant.

### Search
To find a word, number or phrase in a long document without reading all of it, use the new `distill_search` MCP tool or the CLI:

```bash
distill-llm grep "termination clause" contract.pdf
distill-llm grep --regex "Q[1-4] 20\d\d" report.pdf --json
```

- Each hit comes with its physical page, the nearest heading and a few lines of context.
- Matching ignores case and line wraps.
- It works on PDFs, Office files, web pages and transcripts.
- `--regex` uses RE2 syntax, so a pathological pattern can't hang the tool.

### Also
- The Docker image includes ffmpeg and can install the speech runtime.

### Upgrading
- **Web or desktop app:** the update banner.
- **Global npm install:** `distill-llm update`.
- **npx:** `npx distill-llm@latest`.
- **Docker:** `docker pull ghcr.io/nievesjesus/distill`.
- **Claude Code plugin:** `claude plugin update distill@distill`.
