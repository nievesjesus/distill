## distill 0.5.0

### Large documents: read only what you need
distill now builds an index of each document: its sections (or its pages, when there are no headings), with line ranges, page numbers and token counts. Agents load the index first and then only the section they need.

- **Claude Code hook:** when a document is over 8,000 tokens, `Read` loads the index and the first part, then the agent reads sections with `offset` and `limit`.
  - Set the threshold with `DISTILL_INDEX_MIN_TOKENS`; `0` turns the index off.
- **MCP:**
  - `distill_outline` is a new tool that returns the index.
  - `distill_file` accepts `section` (a heading from the index) or `limit`.
  - When a document comes back in parts, the first part includes the index.
- **CLI and Office skill:**
  - `distill-llm outline <file>` prints the index.
  - `convert --stdout` gains `--max-tokens`, `--offset` and `--limit`.
  - The Office skill uses these, so large Word, Excel and PowerPoint files are read in parts too.
- **Measured** on a 120-page PDF (~94,500 tokens), with a question about one clause on page 104: the right answer came back with about 10% of the document loaded, through both the hook and MCP.

Also in this area:
- **Page markers:** multi-page PDFs mark each page with `<!-- page N -->`, so agents can cite pages.
- **Long lines:** Claude Code's `Read` cuts lines longer than 2,000 characters, so the hook's cached Markdown splits long paragraphs at sentence boundaries. Tables and code are never touched.

### `distill-llm stats`
- distill keeps a local record of the tokens it saved: totals for all time, the last 30 days and the last 7 days, by source (hook, MCP, CLI) and by file type.
- `--price <usd per million tokens>` adds the dollar value.
- The record holds only dates, sources, file types and token counts, never paths or content. It stays in `~/.cache/distill-llm/stats.jsonl`.
- Turn it off with `DISTILL_NO_STATS=1`.
- The savings note is now counted once per document, so following a section read no longer repeats it.

### Clearer MCP tools
- Every tool is marked read-only, with a title.
- The tool descriptions now say when to use each tool, the limits, the errors to expect and what `boosters` and `lingua` do. `lingua` removes words.
- `distill_capabilities` reports the per-call output cap.

### Claude Code plugin
- If the plugin's pinned `distill-llm` version is not on npm yet, it falls back to the latest release instead of failing.

### Upgrading
- The banner in the web or desktop app, or `distill-llm update` for a global npm install.
- npx: `npx distill-llm@latest`
- Docker: `docker pull ghcr.io/nievesjesus/distill`
- Claude Code plugin: `claude plugin update distill@distill`
