## distill 0.7.0

> 0.6.0 shipped as a GitHub release and desktop update, but it never reached npm: the npm publish step rejected its lockfile. If you install distill through npm, npx or the Claude Code plugin, 0.7.0 is your first release after 0.5.0, so it also contains everything from 0.6.0 (see below).

### See which pages have charts and images
- Until now, a chart or figure in a PDF was lost without warning: the Markdown carried its text, if any, but not the picture.
- distill now marks those pages. A page marker such as `<!-- page 2: figure (chart or image not in this text; see the original page) -->` flags a chart or image, and scanned pages are marked `scan`. The document index shows them too.
- **Claude Code hook:** tells the agent which pages have figures, so it can read only those pages from the original PDF when the question depends on them.
- **MCP:**
  - `distill_file` and `distill_outline` return `visualPages`.
  - The new `distill_page_image` tool returns one PDF page as an image.
- Detection is tuned to skip ordinary tables and small logos, and it adds only a few milliseconds per document. A page that has both a bordered table and a chart is not flagged yet.
- Verified with Claude on a chart whose values only make sense in the picture, through both the hook and MCP.

### Fixes
- Over MCP, savings are now counted once per document per session. Calling `distill_outline` and then `distill_file` reported them twice.
- The npm lockfile is regenerated with npm 12, and CI now checks it with the same npm version that publishes.

### From 0.6.0 (if you are coming from 0.5.0 through npm)
- **`distill-llm agents install`** sets up distill in other coding agents: Codex (and the ChatGPT desktop app), Cursor, OpenCode, Claude Desktop, Gemini CLI, Hermes and OpenClaw. It registers the MCP server and adds a skill for PDF and Office files.
  - Each change is shown and confirmed first; `--dry-run`, `--project` and `agents uninstall` are available.
  - `agents status` shows what is set up where.
  - Verified with real runs on OpenCode, Codex and Cursor.
- **OpenCode 2:** the OpenCode plugin works on OpenCode 1.x and 2.x. To update an existing plugin, run `distill-llm hooks install --opencode` again.
- **Parsing:** LiteParse 2.19 recovers text that was dropped at page tops, and the underline tags it now adds are removed.
- **Security fixes:**
  - A backslash in an Office table cell could break the Markdown table; this was found by CodeQL code scanning.
  - `minimatch` was updated in the desktop build tools.

### Upgrading
- **Web or desktop app:** use the update banner.
- **Global npm install:** `distill-llm update`.
- **npx:** `npx distill-llm@latest`.
- **Docker:** `docker pull ghcr.io/nievesjesus/distill`.
- **Claude Code plugin:** `claude plugin update distill@distill`.
