## distill 0.3.0

### Office files without LibreOffice
- DOCX, XLSX, PPTX and CSV now convert out of the box in every install: npm, npx, the desktop app and the Claude Code / OpenCode hooks. LibreOffice is no longer required for them.
  - **Word:** headings, lists, tables, bold and italic, and links.
  - **Excel:** one GFM table per visible sheet. Empty rows and columns are dropped, and hidden sheets are skipped.
  - **PowerPoint:** one section per slide in presentation order, with titles, text, tables and speaker notes.
- If LibreOffice is installed, distill still uses it for these formats. It gives higher fidelity on layout-heavy files.
- Legacy Office (.doc, .xls, .ppt) and OpenDocument (.odt, .ods, .odp) still need LibreOffice. Docker includes it, as before.
- `distill-llm convert --json` and the HTTP API report which engine converted each file (`engine: "builtin"` or `"liteparse"`).
- Archives are read with safety limits: at most 5,000 entries, 64 MiB per entry and 256 MiB in total. Anything larger is rejected instead of being unpacked.

### Releases
- Releases are now built, verified and published automatically. The update manifests are checked against the real installers before anything goes live, so the desktop auto-update never points at a file that does not match.

### Upgrading
- From 0.2.0: the banner in the web or desktop app, or `distill-llm update` for a global npm install.
- npx: `npx distill-llm@latest`
- Docker: `docker pull ghcr.io/nievesjesus/distill`
