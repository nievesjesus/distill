## distill 0.8.0

### Web pages
Agents read the web all the time. Raw HTML is mostly markup, and Claude Code's WebFetch only shows the model a summary. distill now converts web pages into clean, complete Markdown on your machine.

```bash
distill-llm convert --stdout https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch
```

- **MCP:** the new `distill_url` tool.
  - Long pages come with an index and section reads: `section` matches any heading, and when nothing matches it suggests the closest ones.
  - It uses the same paging, savings note and stats as documents.
- **Tokens:** on 7 real pages, 86–99% fewer than the raw HTML. For example, MDN's "Using Fetch" goes from 48,988 to 5,238.
- **Markdown first:** sites that serve Markdown to agents (`Accept: text/markdown`) are used as served.
- **Full mode:** the main content is extracted with defuddle. If something seems missing (version notes, sidebars, metadata), `mode: "full"` (or `--full`) converts the whole page.
- **Safe by design:**
  - only `http` and `https`;
  - private, loopback and cloud-metadata addresses are refused, checked on every redirect;
  - size and time limits;
  - no cookies or credentials are sent;
  - web content is marked as untrusted.

  The MCP server never reaches private hosts; the CLI can with `--allow-private` or `--allow-host`.
- **Pages that need JavaScript** are reported as such. Save the page from your browser as `.mhtml` and convert the file instead.

### New formats
- **EPUB** (chapters in reading order, with the table of contents; DRM-protected books are refused).
- **Saved pages** (`.html`, `.htm`, `.mhtml`).
- **Email** (`.eml`, `.msg`).
- **RSS/Atom feeds.**

The Claude Code hook also converts `.mhtml`, `.epub`, `.eml` and `.msg` when Claude reads them. It does not touch `.html` or `.xml`, so editing source files is not affected.

### Long PDFs in Claude Code
On long PDFs, Claude's Read asks for specific pages (`pages: "1-3"`), and until now distill stepped aside for those reads. The hook now returns just those pages as Markdown, with the savings for those pages.
- If every requested page is a chart or figure, Claude reads the originals instead.
- Pages are matched by their physical position in the file, not by their printed labels.
- In `distill_file` and `distill_outline`, each entry in `visualPages` now has a physical `page` number and, when it differs, the printed `label`.

### Also
- `DISTILL_CACHE_DIR` moves distill's cache from its default `~/.cache/distill-llm`, for sandboxes, CI or shared machines.
- distill now has an end-to-end benchmark in its own repository, [distill-bench](https://github.com/nievesjesus/distill-bench). It runs Claude Code with and without distill on public documents and reports where distill helps and where it doesn't.

### Upgrading
- **Web or desktop app:** the update banner.
- **Global npm install:** `distill-llm update`.
- **npx:** `npx distill-llm@latest`.
- **Docker:** `docker pull ghcr.io/nievesjesus/distill`.
- **Claude Code plugin:** `claude plugin update distill@distill`.
