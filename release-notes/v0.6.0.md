## distill 0.6.0

### One command for your other coding agents

```bash
npm i -g distill-llm
distill-llm agents install --codex --cursor --opencode --claude-desktop
```

- `distill-llm agents install` sets up distill in the coding agents you use: it registers the MCP server and adds a skill for PDF and Office files.
  - Supported flags:
    - `--codex` (this also covers the ChatGPT desktop app, which shares Codex's config)
    - `--gemini`, `--cursor`, `--opencode`, `--claude-desktop`, `--hermes`, `--openclaw`
    - `--all` for every agent it finds
  - Like `hooks install`, it shows each change and asks first. It also offers `--dry-run`, `--project` and `distill-llm agents uninstall`.
  - It never overwrites an entry or skill you wrote yourself.
- `distill-llm agents status` shows what is set up for each agent.
- **Each agent's own tool does the setup when it has one** (`codex mcp add`, `gemini mcp add` and so on). When it doesn't, distill prints the exact lines to add yourself.
- **The server is registered with absolute paths,** so apps opened from the Dock, Finder or Start menu (Cursor, Claude Desktop, the ChatGPT desktop app) find it. Run `agents install` again after upgrading Node.
- **One skill serves most agents.** `distill-documents` goes in `~/.agents/skills`, which Codex, Cursor, OpenCode, OpenClaw and Gemini read. Hermes gets its own copy.

Verified on 2026-11-19 with real runs. In each one, a question could only be answered from a PDF and a DOCX:
- **OpenCode:** through the MCP server.
- **Codex CLI:** through the skill, inside its sandbox.
- **Cursor CLI:** through the MCP server. If you have another document-conversion skill installed, ask for distill by name.
- **Gemini CLI:** configured but not run, because Google no longer offers it to individual accounts.
- **Hermes Agent and OpenClaw:** configuration only.
- **Antigravity:** not supported yet.

### OpenCode 2
- OpenCode 2 changed its plugin API and the name of the read tool's path argument. The distill OpenCode plugin now works on OpenCode 1.x and 2.x; it was tested on 1.2.27, 1.19.6 and 2.3.2.
- Run `distill-llm hooks install --opencode` again to update an existing plugin.
- On OpenCode 1.19 and later, reading distill's cache may need the `external_directory` permission. The README shows how.

### Parsing
- LiteParse 2.19 recovers text that 2.18 dropped at the top of some pages.
- The "Slim images and links" booster now also removes the underline tags (`<u>`) that LiteParse 2.19 adds.

### Fixes
- Office tables and text: a backslash in a Word, Excel or PowerPoint cell could cancel the escaping of a `|` or `*` and break the Markdown table. Backslashes are now escaped too. This was found by CodeQL code scanning, which now runs on every change.
- Desktop build tools: `minimatch` was updated to 11 for electron-builder's dependencies to fix a denial-of-service advisory. It only affected building the desktop app, not the npm package.

### Upgrading
- Use the banner in the web or desktop app, or `distill-llm update` for a global npm install.
- npx: `npx distill-llm@latest`.
- Docker: `docker pull ghcr.io/nievesjesus/distill`.
- Claude Code plugin: `claude plugin update distill@distill`.
