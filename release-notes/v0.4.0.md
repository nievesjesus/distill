## distill 0.4.0

### Claude Code plugin
Install everything with two commands:

```bash
claude plugin marketplace add nievesjesus/distill
claude plugin install distill@distill
```

- The plugin brings three things:
  - the Read hook for PDF and Office files
  - the `distill` MCP server
  - the Office skill
- No settings to edit and no global install.
- It runs `distill-llm` through `npx`, pinned to the plugin's version. It needs Node.js 22.12 or newer, and the first conversion downloads the package.
- The hook now approves reading its own cached Markdown, so Claude no longer asks for permission. Your `deny` and `ask` rules still apply, and the hook steps aside when one of them could match the file.
- If you already use `distill-llm hooks install --claude`, the plugin's hook steps aside, so files are not converted twice. Remove one of the two with `distill-llm hooks uninstall --claude`.

### See what distill saves
- Every MCP result, every hook read (cached or fresh) and `convert --stdout` now carry a line like this:
  `[distill] tokens saved ≈ 12,665 (84%) — this Markdown ≈ 2,394 tok vs reading the original ≈ 15,059 tok`
  The agent is asked to report the total at the end of its reply, for example "💧 distill saved ~23,667 tokens this turn".
- How the comparison is made:
  - **PDFs:** against reading the PDF directly, estimated as the text plus about 1,560 tokens per page. This was calibrated against Anthropic's token counter, within ±3% per document.
  - **Office files:** against the raw extracted text.
- Turn the line off with `DISTILL_NO_SAVINGS_NOTE=1`.

### Large documents over MCP
- `distill_file` now returns large documents in pages of up to 10,000 tokens. Each page includes `nextOffset`, and agents pass it as `offset` to read the next one.
  - Before, a document past roughly 40 pages overflowed Claude Code's tool-result limit.
  - Conversions are cached in memory, so reading the next page does not convert the file again.
- `distill_files` shares the same budget across files. A file that does not fit comes back in part, and the files after it are skipped with a hint.
- Change the page size with `DISTILL_MCP_MAX_TOKENS`.
- Relative paths resolve against the server's working directory.

### Official MCP registry
- distill is now published to the official MCP registry as `io.github.nievesjesus/distill`, and every new release is listed there automatically.

### Upgrading
- From 0.2.0 or later, use the banner in the web or desktop app, or run `distill-llm update` for a global npm install.
- npx: `npx distill-llm@latest`
- Docker: `docker pull ghcr.io/nievesjesus/distill`
